# DeepBI Amazon 广告经营指南

本指南补充 README 中的核心方法，聚焦不同经营阶段和商品结构下的判断方式。

## Listing 和广告必须一起看

广告有点击，没有订单，并不一定意味着广告出了问题。广告解决的是把合适的消费者带到页面；Listing 解决的是消费者来到页面以后，为什么要买你。

因此需要同时检查：

- 主图是否让买家快速理解产品；
- 标题是否先讲清核心需求；
- 五点是否回答购买顾虑；
- A+ / 详情页是否完成持续说服；
- 产品与竞品相比是否具备足够竞争力。

如果页面无法承接流量，继续增加预算，只会把更多买家送到一个无法完成转化的页面。这也是 DeepBI 同时提供 Listing 优化和 AI 广告优化的原因。

## Target ACOS：不是越低越好

DeepBI 中一个非常重要的概念是 **目标 ACOS（Target ACOS）**。它并不是一个“越低越优秀”的成绩，更准确地说，它是卖家给 AI 设置的经营目标和约束。

### 新品探索期

新品没有足够历史数据。如果一开始就把目标 ACOS 压得非常低，广告可能很难获得足够流量完成测试。这个阶段更重要的是：用合理成本找到真正能够产生订单的流量。

### 稳定增长期

当广告已经跑出一批稳定关键词和流量入口，同时库存充足、利润空间允许时，继续压低 ACOS 未必是最佳选择。更合理的做法可能是保持能够盈利的 ACOS 区间，同时增加预算，放大已验证的订单机会。

### 库存或利润压力期

当库存不足、补货周期变长、产品利润下降或市场转化发生变化时，广告策略也应该重新收紧。因此，**Target ACOS 应该跟着产品经营阶段变化。**

## 多变体 / 多 SKU 怎么处理？

Amazon 父 ASIN 下可能包含多个颜色、尺码或规格 SKU。DeepBI 不会简单地为每个 SKU 人工拆分一套关键词广告，而是在 Amazon 自身曝光与匹配机制的基础上，根据不同 SKU 的真实广告和经营数据继续调整投放。

随着数据积累，系统通常会逐渐发现某些 SKU 在当前阶段表现更好，并让这些“主推 SKU”获得更多有效流量。但主推 SKU 不是永久固定的：库存、价格、转化率、消费需求和竞争环境都会变化。

DeepBI 更强调根据当前数据持续选择更值得投入的 SKU，而不是提前永久固定一个主推款。卖家也可以根据库存、利润和经营计划，对具体子 SKU 的广告投放进行控制。

## 新品广告怎么跑？

新品最大的问题是没有自己的历史数据。因此，DeepBI 不把新品推广理解成“找到几个关键词，然后开始猛推”，而是依次建立初始流量池、探索关键词与竞品 ASIN、获得真实点击和转化数据、筛选有效流量、减少低价值流量，再放大已经验证的机会。

> **先探索，再验证，再放大。**

## 节日、大促与季节性流量

返校季、Prime Day、黑五、圣诞节，以及大量类目季节性需求，都具有同一个特点：**流量来得快，走得也快。**

广告系统不仅需要发现机会，也要识别机会何时开始失效。例如，一个返校季场景词可能在活动前期不断提升转化，在黄金销售期快速放量；但需求结束后，即使仍有点击，转化价值也可能迅速下降。

DeepBI 会持续观察数据变化，及时调整竞价和投入。因此，AI 的价值既在于更早进入机会，也在于更早发现机会已经结束。
