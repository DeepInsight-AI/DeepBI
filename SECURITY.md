# Security Policy

## Supported Versions

We release regular updates to DeepBI.  
Please ensure you are using the latest version to receive the most recent security patches.

| Version | Supported          |
|---------|--------------------|
| Latest  | ✅ Supported        |
| Older versions | ❌ Not actively supported |

---

## Reporting a Vulnerability

If you discover a security vulnerability in DeepBI, **please report it responsibly**.

We strongly encourage you to privately disclose security issues to us before publishing them publicly.

### How to Report

- Email us at **dev@deepbi.com** with the subject line: `[Security Disclosure]`
- Provide a clear description of the vulnerability, including:
  - Affected versions
  - Steps to reproduce
  - Potential impact
  - Any relevant proof-of-concept (PoC) code if available

We aim to respond to all security reports within **5 business days**.

---

## Our Commitments

- We will acknowledge receipt of your report promptly.
- We will investigate and validate the vulnerability.
- We will work on a timely resolution and coordinate a public disclosure timeline with you.

## Thank You

We greatly appreciate the efforts of the security community to help keep DeepBI safe and secure!
